Plugin player

Plays plugins in this browser. A plugin shared as a link opens by itself. A plugin shared as a file is imported here, and then opens from the library.

Import

An imported plugin runs its own code in this player, with the player's permissions, and can see the other plugins imported here. Only import plugin files you trust.

A folder is imported without its hidden files and folders, those whose names start with a dot.
